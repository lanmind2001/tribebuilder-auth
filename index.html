TribeBuilder

An iOS SDK and app for multi-platform social media publishing. Built with Swift, SwiftUI, and SwiftData — designed for independent music artists.

Swift 5.9 iOS 17+ SwiftUI SwiftData

Architecture

TribeBuilder is built as a modular iOS application using modern Swift concurrency, SwiftUI for the UI layer, and SwiftData for persistence. The publishing pipeline supports multiple social platforms through a unified protocol-based interface.

// Unified publisher protocol
protocol SocialMediaPublisher {
  var platform: SocialPlatform { get }
  func publishText(_ text: String, mediaURLs: [URL]?) async throws -> PublishResult
  func refreshToken(_ tokens: OAuthTokens) async throws -> OAuthTokens
}

Content Generation

Multi-provider AI content generation with BYOK support for ChatGPT, Gemini, Grok, DALL-E, and Gemini Vision.

Publishing Pipeline

Three-tier fallback publishing with retry logic, offline queue, and background task scheduling via BGTaskScheduler.

OAuth Management

Unified OAuth 2.0 + PKCE flow for all platforms with proactive token refresh and Keychain-backed secure storage.

Strategy Engine

AI-powered content strategy planning with persona matching, auto-scheduling, and review queue for generated content.

Supported Platforms

TribeBuilder integrates with major social media platforms through their official APIs:

TikTok

Content Posting API v2 — photo (PULL_FROM_URL) and video (FILE_UPLOAD) with three-tier post mode fallback.

Instagram

Graph API — photo and carousel publishing with image hosting via Supabase Storage.

YouTube

Data API v3 — video upload with metadata, privacy settings, and channel management.

X / Twitter

API v2 — tweet posting with media upload, thread support, and OAuth 2.0 PKCE.
